# بناء تطبيق Nomi

## النتيجة
تحويل الواجهة الحالية إلى تجربة **Nomi** كاملة، يكون الشات الدائم هو الصفحة الرئيسية، مع ترحيب أول مرة، شخصية كرتونية تظهر بذكاء، وصفحة مكالمات غامرة. لن تُحذف جداول Megsy القديمة ولن تُستخدم لبيانات Nomi الجديدة.

## ما سيتم بناؤه

### 1. هوية وتجربة Nomi
- نظام ألوان وخطوط وحركات جديد: ودود، بسيط، فاخر، ومريح في الوضعين الفاتح والداكن.
- واجهة تطبيق موحدة للهاتف والكمبيوتر، بلا لوحة تحكم منفصلة.
- تنقل مختصر إلى: الشات، المكالمات، الذاكرة، تخصيص Nomi، والإعدادات.

### 2. صفحة الترحيب والإعداد الأول
- تظهر قبل الشات للمستخدم الجديد فقط.
- اختيار شكل الشخصية وألوانها واسمها وشخصيتها ونبرة كلامها.
- معاينة حية للشخصية أثناء التخصيص.
- بعد الإكمال ينتقل المستخدم إلى الشات الدائم ولا تظهر الصفحة مرة أخرى إلا بطلبه.

### 3. الشات الرئيسي الدائم
- `/` و`/chat` يفتحان نفس محادثة Nomi الأساسية بدل إنشاء محادثات متفرقة.
- الرسائل والمهام والتذكيرات والملخصات تظهر داخل مجرى الشات نفسه.
- مربع كتابة ثابت ونظيف، مع إجراءات واضحة للصوت والإرفاق والإرسال.
- الأفاتار ليس ثابتًا على الشاشة؛ يظهر سياقيًا عند الترحيب، الاستماع، الكلام، الإنجاز، أو عند استدعائه.
- حركة وجه وفم خفيفة أثناء الكلام، مع احترام خيار تقليل الحركة.

### 4. المكالمات
- صفحة مكالمة كاملة تركز على الشخصية.
- ألوان متحركة على حواف الشاشة تتفاعل بصريًا مع حالة الاستماع والكلام.
- أدوات كتم الصوت، مكبر الصوت، وإنهاء المكالمة.
- في الإصدار الأول ستكون تجربة الواجهة والصوت داخل المتصفح؛ ربط المكالمات الهاتفية الخارجية يبقى مرحلة لاحقة.

### 5. الذاكرة والخصوصية والإعدادات
- صفحة ذاكرة منظمة تعرض ما حفظه Nomi مع حذف أو إيقاف عناصر بعينها.
- صفحة صلاحيات واضحة للبريد والتقويم والويب والميكروفون.
- تخصيص الشخصية والصوت والنبرة من الإعدادات في أي وقت.
- الإبقاء على تسجيل الدخول الحالي مع إعادة تغليف صفحاته بهوية Nomi.

### 6. قاعدة البيانات المعزولة
إنشاء جداول جديدة فقط بأسماء تبدأ بـ `nomi_`، مثل:
- `nomi_companions`: شكل الشخصية واسمها وشخصيتها وصوتها.
- `nomi_threads`: محادثة Nomi الدائمة لكل مستخدم.
- `nomi_messages`: رسائل المحادثة.
- `nomi_memories`: الذكريات مع درجة الحساسية وإمكانية التعطيل.
- `nomi_permissions`: صلاحيات الأدوات والخدمات.
- `nomi_call_sessions`: سجل جلسات المكالمات وحالتها.

كل جدول سيكون محميًا بحيث يرى ويعدل كل مستخدم بياناته فقط، مع منح الصلاحيات المطلوبة للمستخدم المسجل وخدمة الخادم. لن نغيّر أو نحذف جداول التطبيق القديم.

## التفاصيل التقنية
- بناء تجربة Nomi بالكامل داخل تطبيق React الحالي، من دون استخدام بنية صفحات TanStack أو إضافة صفحات إليها؛ سيبقى غلاف التشغيل الحالي غير المرئي فقط لأن الاستضافة تعتمد عليه.
- إعادة استخدام تسجيل الدخول الحالي، مع إبقاء أسرار المزودين خارج المتصفح.
- إضافة البيانات عبر migration واحدة تشمل الجداول والفهارس والمنح وسياسات الحماية.
- تحديث بيانات العنوان والوصف والمشاركة باسم Nomi.
- دعم الإنجليزية والعربية واتجاه RTL من البداية.
- اختبار المسار الكامل على الهاتف والكمبيوتر في الوضعين الفاتح والداكن: الترحيب ← إنشاء الشخصية ← الشات ← ظهور الأفاتار ← المكالمة ← الذاكرة والإعدادات.

## حدود النسخة الأولى
- لا حذف فعلي لكود أو بيانات Megsy القديمة؛ سيتم إخراجها من المسار الرئيسي مع إبقائها آمنة للرجوع.
- لا تنفيذ لاتصالات هاتفية حقيقية أو ربط بريد/تقويم خارجي دون إعداد خدماتها؛ سنبني الواجهات والصلاحيات والاستعداد للربط.
